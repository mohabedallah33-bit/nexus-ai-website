# 🤖 Nexus AI - مساعد الكمبيوتر الذكي

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-327873?style=for-the-badge&logo=github)](https://mohabedallah33-bit.github.io/nexus-ai-website/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

مساعد ذكاء اصطناعي متقدم لنظام Windows يتعلم من استخدامك اليومي ويتطور مع الوقت.

## ✨ الميزات الرئيسية

### 🧠 التعلم الذكي
- **تعلم من الاستخدام اليومي**: يتعلم أنماطك وعاداتك
- **اقتراحات ذكية**: يقترح أوامر بناءً على الوقت وتاريخك
- **تتبع الأوامر**: يحلل الأوامر الأكثر استخداماً
- **التعلم التلقائي**: يتعلم سلاسل الأوامر المتكررة

### 🎤 الدردشة الصوتية
- تحدث مع المساعد صوتياً
- التعرف على الصوت بدقة عالية
- ردود صوتية طبيعية

### 🎨 إنشاء الصور
- طلب إنشاء صور بالذكاء الاصطناعي
- دعم مولدات صور متعددة
- حفظ الصور تلقائياً

### ☁️ المزامنة السحابية
- مزامنة الذاكرة بين النسخ المختلفة
- ما تتعلمه في نسخة ينتقل لجميع النسخ
- دعم مزودات سحابية متعددة

### 🛡️ لوحة تحكم المالك
- مراقبة الأخطاء وحلها
- كشف سوء الاستخدام
- إحصائيات تفصيلية
- تصدير التقارير

### 💻 أدوات البرمجة
- إنشاء المشاريع
- كتابة وتعديل الأكواد
- تشغيل Python
- إدارة Git
- تنفيذ أوامر التطوير

## 🚀 التحميل

الموقع الرسمي: [https://mohabedallah33-bit.github.io/nexus-ai-website/](https://mohabedallah33-bit.github.io/nexus-ai-website/)

## 📖 كيفية الاستخدام

1. **تحميل التطبيق** من الموقع الرسمي
2. **تشغيل Nexus AI.exe**
3. **إدخال مفتاح Gemini API** (مجاني من [Google AI Studio](https://makersuite.google.com/))
4. **ابدأ المحادثة!**

## 🔧 التقنيات المستخدمة

- **Python 3.12** - اللغة الأساسية
- **Google Gemini AI** - محرك الذكاء الاصطناعي
- **CustomTkinter** - واجهة المستخدم
- **PyAutoGUI** - أتمتة النظام
- **Speech Recognition** - التعرف على الصوت
- **PyInstaller** - بناء EXE

## 📝 الأوامر الرئيسية

```
تحليل الاستخدام      - عرض تقرير الاستخدام اليومي
أنماط اليوم          - عرض الأنماط المتعلمة
مفعل التعلم          - تفعيل التعلم التلقائي
عطل التعلم           - إيقاف التعلم التلقائي
لوحة المالك          - فتح لوحة تحكم المالك
حالة المزامنة        - عرض حالة المزامنة السحابية
مزامنة الذاكرة       - رفع الذاكرة للسحابة
تحميل الذاكرة        - تحميل الذاكرة من السحابة
```

## 🛠️ التطوير

```bash
# تثبيت المتطلبات
cd pc-assistant
pip install -r requirements.txt

# تشغيل التطبيق
python main.py

# بناء EXE
build.bat
```
